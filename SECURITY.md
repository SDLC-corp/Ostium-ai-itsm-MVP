# Security Policy

This repository is a demonstration MVP. Before you expose it to the internet:

- Set `OSTIUM_API_KEY` so that write operations require authentication.
- Put the app behind a TLS-terminating reverse proxy.
- Remove or protect `POST /api/v2/admin/reset`.

To report a vulnerability, contact SDLC Corp privately through https://sdlccorp.com/products/ostium/ rather than opening a public issue.
